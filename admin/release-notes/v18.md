This is the first release using **dataset schema 2**.

- **Size-specific outlines:** optional `variants` let products use different silhouettes for sizes with different proportions. Each variant has its own size assignments, quality rating, and source.
- **Consistent units:** independent product measurements are now always published in inches (`unit: "in"`). Existing metric measurements have been converted.

Consumers should accept `schema_version: 2` and check for an assigned variant before using the general outline. A variant marked `unusable` means those sizes have no usable outline; it must not fall back to the general outline. SVG scaling remains unchanged.

See the [dataset format guide](https://github.com/quittung/silicone-shadows/blob/v18/docs/dataset-format.md) for examples and selection rules.
