How to review a silhouette

1. Check the mask

The shaded area is background. Use Add to include missing product areas and Erase to remove background, shadows, or reflections. Only the largest connected foreground object is exported.

2. Mark the usable length

Select Length, then mark only the usable portion from its usable base toward the tip. Exclude suction cups, handles, and other non-usable parts. The arrowhead must point toward the tip; use Reverse if needed.

3. Rate the source

  • Good: the silhouette is suitable for shape comparison.
  • Bad perspective: traceable, but visibly distorted by the camera angle.
  • Unusable: no trustworthy silhouette can be produced from this image.

Use Search images, then paste or drop a better source when needed. Press Space to save and continue. Usable entries require a usable-length line.

Existing dataset entries open read-only. Choose Re-review only when you intend to replace the published result.
